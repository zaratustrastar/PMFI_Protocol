## 2) Why you previously got “invalid signature”

You had a working authenticated client, but the API rejected the order signature. That usually happens when **the address used for signing / order payload doesn’t match what the server expects**.

In your case you explicitly have two identities:

* **EOA signer**: `0x5087…`
* **proxy/funder**: `0x9cbc…`

Depending on the `py_clob_client` version, one of these must be treated as the “trading address”, and the other as the “funder”. If you force the proxy wallet as “wallet address” in a way the library doesn’t support, you get signature mismatch.

So step-by-step:

* **Remove `set_wallet_address`**
* Ensure the constructor is the *only* place you set funder/proxy
* Then check if the library expects `signature_type=1` (some versions do, some don’t)

## 3) Make your code version-proof (recommended)

Drop-in helper that adapts to whatever `ClobClient.__init__` supports:

```python
import inspect
from py_clob_client.client import ClobClient

def make_clob_client(host, pk, chain_id, proxy_addr=None):
    sig = inspect.signature(ClobClient.__init__)
    kwargs = {}

    # common params
    if "key" in sig.parameters:
        kwargs["key"] = pk
    if "chain_id" in sig.parameters:
        kwargs["chain_id"] = chain_id

    # only include if supported in your version
    if "signature_type" in sig.parameters:
        kwargs["signature_type"] = 1

    # proxy/funder support varies by version
    if proxy_addr:
        if "funder" in sig.parameters:
            kwargs["funder"] = proxy_addr
        elif "wallet" in sig.parameters:
            kwargs["wallet"] = proxy_addr
        elif "address" in sig.parameters:
            kwargs["address"] = proxy_addr

    return ClobClient(host, **kwargs)
```

Then use:

```python
client = make_clob_client(
    "https://clob.polymarket.com",
    normalized_key,
    137,
    proxy_addr=PM_PROXY_ADDRESS
)
```

This prevents you from calling methods/kwargs that don’t exist in the installed version.

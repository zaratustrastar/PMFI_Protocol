# Root cause: resolve_tradable_market tried /market/{id} (binary) FIRST.
# For categorical parents like market 340, this returns errno=10200 
# "Topic ID does not exist" — wasting a round-trip. Then Path 2 
# (/market/categorical/{id}) does work and returns children, BUT:
#   - It didn't filter out Resolved children
#   - The outcome_hint scoring was ambiguous for generic hints like "yes"
#   - The Oddpool label field ("↑ 120,000") was never used for matching
